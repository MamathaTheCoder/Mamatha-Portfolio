# K.P. Mamatha - Personal Portfolio

## 📌 Project Overview

This project is a responsive personal portfolio web application developed as part of the Full Stack Development assignment.

The portfolio showcases my personal profile, academic background, technical skills, projects, achievements, and contact information.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6+)

## ✨ Features

- Responsive personal portfolio
- Semantic HTML5 structure
- Responsive Bootstrap navigation bar
- Home, About, Education, Skills, Projects, Achievements and Contact sections
- Project filtering by category
- Light/Dark theme switching
- Typing animation
- Contact form with client-side validation
- Dynamic success and error messages
- Scroll-to-top button
- Responsive design for mobile, tablet and desktop
- Keyboard accessibility features
